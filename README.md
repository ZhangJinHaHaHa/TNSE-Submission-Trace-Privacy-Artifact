# Public experimental artifact

Supporting material for **Auditable Submission-Trace Privacy for Stateful Trading Agents**.

Authors: Jinghan Zhang, Jiyuan Song, and Zhaofeng Ma.

## Download

- [Public experimental artifact ZIP](TNSE_Public_Experimental_Artifact_2026-10-21.zip)
- [Archive SHA-256 checksum](TNSE_Public_Experimental_Artifact_2026-10-21.zip.sha256)

This is a separately prepared public subset of the submission supplement, not a new experimental run and not a byte-identical copy of the journal submission package. The original submission files remain unchanged.

The archive retains author code, synthetic experiments, aggregate historical-replay and language-model results, physical-board execution diagnostics, acquisition instructions, and integrity/provenance records. Restricted LOBSTER row-level market data and reconstructable embedded observations are excluded. Qwen2.5 raw completions and action rows are omitted; retained canonical parse records are explicitly marked public derivatives with action values removed. These derivatives cannot replace the withheld raw evidence or enable independent raw-text re-parsing.

After extraction, start with `README.md`, `PUBLIC_FILE_INVENTORY.csv`, `PUBLIC_CHANGELOG.json`, and `PUBLIC_REBUILD_INSTRUCTIONS.md`. The current `SHA256SUMS.txt` and verifier cover both rebuilt nested archives. Historical manifests are provenance records, not current public-release inventories.

Hardware records document execution of the portable experimental harness, not independent hardware certification or deployment of a complete live trading system. The public subset does not establish venue-wide privacy or trading profitability.
